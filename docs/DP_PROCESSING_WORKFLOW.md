# 🤖 DP 题库处理工作流 v1.0

> 给 DP（DeepSeek）/ ChatGPT 等大模型用的**强制工作流**。
>
> 经验证：直接让 AI 一次性处理大题库会出现严重错乱（漏答案、多题挤一行、
> 选项错位、章节标签污染等）。本文档把任务拆成**强制分批 + 自检 + 修复**
> 的流水线，降低 AI 走神出错的概率。
>
> **如何使用**：把第 1 节"完整 Prompt"粘进 DP 对话框，按节奏发输入。
> DP 每批处理后必须按第 6 节自检，不通过就重做该批。

## 一、完整 Prompt（粘贴即用）

> ⚠️ 复制下面整段，粘到 DP 对话框，按 Enter 发送。
> 收到 DP "我已收到并理解" 后，再发题库文件。

```text
你是题库处理专家。我会发给你一份原始医学题库（PDF/DOCX/TXT），
你必须严格按下面的工作流处理，输出一份能直接导入手机搜题 App 的标准 Excel。

⚠️ 你**之前的处理常常出错**，原因是一次处理太多、不自检、走神。
现在按强制工作流执行：

━━━━━━━━━━ 强制工作流 ━━━━━━━━━━

【第 1 步】阅读规范
  我会贴一份《标准 Excel 格式规范》给你。先读完，明确"题干/题型/选项/答案"
  各列的填法。读完回复"规范已理解"，并复述 4 条核心规则。

【第 2 步】分析原文结构
  我把题库发给你。你不要急着处理！先用 3-5 句话告诉我：
  - 原文是什么格式？（编号、答案标记位置、选项排版）
  - 有没有 A3/A4 案例题、B 型题、填空题？比例大概多少？
  - 答案是怎么标的？（红字/括号/单独行？）
  - 你预估能切出多少道独立的题？

【第 3 步】小批量处理（每次最多 30 题）
  我会让你按"题号区间"分批处理，例如"第 1-30 题"。
  每批输出一段 Excel-style 的 TSV（Tab 分隔），格式见后。
  每批处理完必须做自检（第 4 步），通过才能下一批。
  禁止：一次性处理 100+ 题。

【第 4 步】批内自检
  每批处理后立刻输出"自检报告"，必须列：
  - 本批题号范围（如 1-30）
  - 实际成功处理 N 道
  - 各题型分布（单选 X / 多选 X / 填空 X / 判断 X）
  - 抽样展示 3 道完整数据
  - 答案为空的题数（必须 = 0）
  - 题干含 "题号前缀/章节标签" 的题数（必须 = 0）
  - 多道题挤一行的题数（必须 = 0）
  自检不通过 → 重做这批。

【第 5 步】合并 + 最终统计
  全部分批完成后，给我汇总:
  - 总题数
  - 4 种题型分布
  - 失败题 + 原因
  - 输出最终 .xlsx（如果太大可以分段输出 TSV，我用脚本合）

━━━━━━━━━━ 输出格式 ━━━━━━━━━━

每批的输出格式（TSV，Tab 分隔，方便我复制到 Excel）：

题干\t题型\t选项A\t选项B\t选项C\t选项D\t选项E\t选项F\t选项G\t选项H\t正确答案

每一行就是一道完整题。不能跨行。一道题的所有内容都必须在同一行的对应列。

━━━━━━━━━━ 11 条硬规则 ━━━━━━━━━━

1. 一道题 = 一行 TSV，不能多题挤一行，不能一题拆多行
2. 题干列：只填题目正文，不要题号（"3、"）、章节（"一、A1型题"）、答案括号（"(C)"）
3. 题型列：必须是【单选题/多选题/判断题/填空题】4 个之一
4. A1/A2/A3/A4/B1 型题 → 都归"单选题"
5. 选项列只填内容，不要"A."前缀
6. 单选答案 = 单字母（A/B/C/D/E）
7. 多选答案 = 连续字母无分隔（ABCDE，不是 "A、B、C" 也不是 "A,B,C"）
8. 判断题答案 = A（对）/ B（错）
9. 填空题答案 = 文字（多空用 | 分隔）
10. 答案列绝对不能为空。如果原文找不到答案，**不要瞎填**，跳过这道题并在自检报告里列出
11. 案例题（A3/A4）：每个子问题独立成一行，stem = 精简案例(60-100字) + 句号 + 子问题题干

━━━━━━━━━━ 开始 ━━━━━━━━━━

现在请：
1. 回复 "规范已收到，准备好"
2. 复述上面 11 条硬规则（不要漏）
3. 然后等我发题库文件

不要主动开始处理，等我下指令。
```

## 二、为什么要分批 + 自检

### 直接处理的失败案例

之前 DP 输出的 12666 行 Excel，问题：
- **正确答案列 12666 行全空**（致命）
- **题干列多题挤一行**："...初步诊断为：胎膜早破者..."
- **选项错位**：A-D 是题 1 的，E 是别道题的
- **章节污染**："一．单选题（共1433题）" 进了题干

根本原因：**AI 一次处理太多，丢失上下文/边界 → 走神**。

### 分批 + 自检的优势

| 维度 | 直接处理 | 分批 + 自检 |
|---|---|---|
| 输出准确率 | 30-50% | 90%+ |
| 出错排查 | 全量重做 | 只重做出错的批 |
| AI 注意力 | 不断衰减 | 每批重置 |
| 你的工作量 | 收完才发现废 | 即时反馈 |

## 三、第 1 阶段：DP 先读懂规范

发完上面的"开场 Prompt"后，DP 会回复"规范已收到"。

**接着发**：
```
现在发完整规范给你，先读完。读完复述 4 条核心规则：
1. ___（DP 自己说）
2. ___
3. ___
4. ___
```

然后把这份《QUESTION_BANK_STANDARDIZATION_SPEC.md》整份贴给 DP。

**DP 必须复述的 4 条**（如果它没说全，让它重读）：
1. 一道题 = 一行 Excel
2. 题型只能是 4 个标准值
3. 多选答案连写无分隔
4. 答案列绝不能为空，没找到要跳过

## 四、第 2 阶段：识别原文结构

发题库文件给 DP，然后**先不让它处理**：

```
先不要处理。用 3-5 句话告诉我：
1. 这份题库的题号是什么格式？（"1." 还是 "1、" 还是 "(1)"）
2. 答案怎么标？（红字/括号/单独行/题号后括号）
3. 大约有多少道题？4 种题型各占多少？
4. 有没有 A3/A4 案例题、B 型题？
5. 有没有看起来会出问题的部分？
```

DP 回答后，**你看一遍**，确认：
- 题号识别对不对
- 答案标记位置识别对不对
- 题量估算合理不（如果原文说"20000题"但 DP 说"500 题"，肯定题号识别错了）

不对就纠正：
```
你说的题号是"1."，但我看了一下原文是"1、"（中文顿号）。
重新分析一遍。
```

## 五、第 3 阶段：分批处理（每批 ≤ 30 题）

确认结构后，**发下面这段**：

```
好，开始分批处理。第一批：处理"第 1-30 题"。

输出格式（每行一道题，Tab 分隔 11 列）：

题干\t题型\t选项A\t选项B\t选项C\t选项D\t选项E\t选项F\t选项G\t选项H\t正确答案

处理完立刻给我自检报告（见 Prompt 第 4 步）。

不要多处理，30 题就是 30 题。等我说"下一批"再继续。
```

**关键**：每批 ≤ 30 题。 经验值：
- 单选/填空题：30 题/批
- 多选题：20 题/批
- 案例题（A3/A4，每题展开 3-5 个子题）：5-8 个案例 / 批

## 八、错误恢复策略

| 问题 | 处置 |
|---|---|
| 某批自检不过 | 让 DP 重做该批 |
| DP 连续 3 批都错 | 重发"开场 Prompt"，让它重新读规范 |
| 某些题原文找不到答案 | 让 DP 列出来，**你手工补**或问客户 |
| DP 处理到一半"忘了"格式 | 重发"11 条硬规则"提醒 |
| 输出总题数比预期少很多 | 多半是 DP 跳过太多，让它列跳过原因 |

## 九、常见 DP 错误 + 修复话术

### 错误 1：答案列空

**修复话术**：
```
我抽查第 X 题，原文明明有"答案: B"（在题目下方），
但你输出的答案列是空的。

把原文的答案标记位置告诉我（题号后括号？选项后？单独一行？），
然后把没填答案的题全部重做。

⚠️ 答案列空 = 这道题废了。绝对不能空。
```

### 错误 2：多道题挤一行

**修复话术**：
```
第 X 行你的题干是："...初步诊断为：胎膜早破者，为防止脐带脱垂..."
这是两道题（一道讲妊高征，一道讲胎膜早破）。

按"一道题 = 一行"规则，把它们拆成两行重做。
```

### 错误 3：题干含章节标签

**修复话术**：
```
第 X 行题干以"一．单选题（共1433题）"开头，这是章节标签不是题目。
去掉这种前缀，从真正的题目正文开始。
```

### 错误 4：选项错位

**修复话术**：
```
第 X 行的选项 E 是"纤维蛋白原变为纤维蛋白"，
但题干是"妊高征诊断"，明显不是同一题的选项。

检查这道题的真正选项在哪，重新填 A-E。
```

### 错误 5：多选答案带分隔符

**修复话术**：
```
你输出的多选答案是"A、B、C、D"，
应该写成"ABCD"（无分隔符，连续字母）。

全文搜索"、"和","在答案列里的全部清理。
```

### 错误 6：A3/A4 案例题没展开

**修复话术**：
```
A3/A4 案例题有共享背景 + 多个子问题（1) 2) 3)）。
按规范，每个子问题独立成一行。

第 X 题（"患儿男 11岁..." 案例）你只输出了 1 行，
应该是 3 行（对应 3 个子问题），重做。
```

### 错误 7：题型识别错

**修复话术**：
```
第 X 行题型你标的是"多选题"，但原文是 A1 型题（单选）。
A1/A2/A3/A4/B1 型题全部归"单选题"。

把所有 X 型题的题型字段统一改成"单选题"。
```

## 十、人工 + 脚本最终验收

### 人工抽样

随机挑 20 道题，**对照原文**：
- 题干一字不差吗？
- 选项内容对吗？
- 答案对吗？
- 题型分类对吗？

如果 20 题里有 > 2 道错 → 整份重做（错误率 > 10% 不可用）。

### 脚本校验

```bash
cd E:\ziyong\aisouti\docs\scripts
python validate_bank.py D:\path\to\your_bank.xlsx
```

校验脚本会输出：
```
━━━━━━━━━━ 校验 your_bank.xlsx ━━━━━━━━━━

Sheet: 题库  总行数: 5421

── 1. 表头检查 ──
  ✓ 表头 11 列 OK

── 2. 行级检查 ──

  错误: 0
  警告: 3
  题型分布: {'单选题': 4200, '多选题': 800, '填空题': 421}
  题干为空: 0
  正确答案为空: 0
  答案格式错: 0
  ...

── 3. 重复检查 ──
  ✓ 无重复题
```

### 三道闸门通过才能导入

| # | 闸门 | 通过标准 |

| 1 | DP 自检报告 | 关键校验项全部 0 |
| 2 | 人工抽样 20 题 | 错 ≤ 2 道 |
| 3 | `validate_bank.py` | 错误数 = 0（警告可接受）|

三关全过再导入 App。任何一关不过，就让 DP 重做。
