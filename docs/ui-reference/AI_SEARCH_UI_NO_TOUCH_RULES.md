# AI 搜题 App UI 规则（不可触犯）

## 总原则

本 App 定位为**工具型 App**：用户在刷题/考试场景下快速搜题。UI 必须克制、干净、不喧宾夺主。

## 必须遵守的规则

### 1. 首页规则

- 产品名必须显示在顶部。
- 产品名下方一行简短说明（不超过 15 字）。
- 首页主操作只有一个："开启悬浮搜题"。
- 权限状态必须一目了然：无障碍服务状态、悬浮窗权限状态。
- 用户中心、检查更新、AI 设置属于低优先入口，不可在首页大面积占用。
- 模式切换（普通/极简）和超时设置属于折叠区，默认不展开。
- 退出按钮放在页面底部。

### 2. 配色规则

- 主色调：工具型中性色，黑白灰为主，辅以单一功能色（如蓝色或深绿）。
- 禁止大面积渐变色。
- 禁止霓虹色（#FF00FF、#00FFFF 等高饱和色）。
- 禁止超过 3 种主色。

### 3. 字体规则

- 标题使用系统默认加粗，字号不超过 28sp。
- 正文使用系统默认常规，字号 14-16sp。
- 状态文案字号 12-14sp。
- 禁止花体、手写体、艺术字。

### 4. 图标规则

- App 图标必须为自有矢量图标，不得使用系统默认图标。
- 悬浮窗按钮使用文字"答"，不使用 emoji。
- 通知图标使用系统内置图标（android.R.drawable）。

### 5. 悬浮窗规则

- 悬浮窗内容区使用玻璃效果（半透明背景 + 轻微描边），但不可多层堆叠。
- 状态文字字号 9sp，答案文字字号 13sp。
- 极简模式使用半透明白色圆形浮点，只显示 1-2 个字符。
- 悬浮窗可拖动，长按触发拖动，短按触发搜题。

### 6. AI 设置页规则

- API Key 输入框使用密码遮蔽（textPassword），不可明文显示。
- 接口地址和模型名输入框使用单行模式。
- 底部显示当前配置摘要（Key 脱敏显示，前4位+****+后4位）。

### 7. 禁止的做法

- 禁止首页全屏动画或自动播放视频。
- 禁止弹窗满天飞（更新弹窗除外）。
- 禁止大段 AI 生成感文案（如"智能助手为您服务"、"AI 赋能学习"等）。
- 禁止使用 Lottie 或复杂动画。
- 禁止首页出现 API 配置项（API Key、Endpoint 等必须在独立的 AI 设置页）。
- 禁止在首页露出 DashScope、千问、豆包等服务商名称。
- 禁止把"后台控额"、"授权状态"等内部概念暴露在首页主区域。

### 8. 品牌与文案规范

- 产品名称：**AI搜题助手**
- 一句话介绍：**悬浮搜题，即搜即得**
- 用户中心按钮：用户中心
- 检查更新按钮：检查更新
- AI 设置按钮：AI 设置
- 退出按钮：退出应用
- 权限状态文案：
  - 无障碍：已开启 / 未开启
  - 悬浮窗权限：已开启 / 未开启
  - 悬浮窗运行：运行中 / 已关闭

## 与华为设备的关系

- UI 不做华为/EMUI 特化，保持标准 Android 风格。
- 华为设备上悬浮窗可能被系统限制，UI 中需要用状态文字提示用户去设置中开启对应权限。
- 不因为华为设备调整布局，仅通过状态文字引导。
