# 🚀 DP 一键 Prompt（全自动 · 自检 · 重试 · 出文件）

> 这份 Prompt **整段复制粘贴**到 DP 对话框，**附上题库原文件**，
> DP 会自动完成全部处理 + 自检 + 重试，最后给你一个可下载的 .xlsx。
>
> **使用步骤**：
> 1. 在桌面新建一个文件夹叫 `新建文件夹`（如果还没有的话）
> 2. 复制 [第二节](#二一键-prompt-复制下面整段) 整段 → 粘到 DP 对话框
> 3. **同时上传**你的题库文件（PDF/DOCX/TXT/Excel 都行）
> 4. 按发送，等 DP 自动跑完
> 5. DP 最终输出可下载 .xlsx → 你点下载，**另存到桌面 `新建文件夹` 里**
> 6. 拿到的 .xlsx 用 `validate_bank.py` 校验一下，通过就能导入 App

---

## 一、使用注意事项

| 项 | 说明 |
|---|---|
| **DP 必须支持文件上传** | DeepSeek / ChatGPT Plus / Claude 都支持 |
| **DP 必须支持生成文件** | 让它输出 .xlsx 让你下载 |
| **题库太大需分文件** | 单文件超 5000 题，把原文件拆成 2-3 份分别处理 |
| **没法生成文件就输出 TSV** | DP 可以输出制表符分隔的文本，你复制到 Excel 里 |
| **桌面新建文件夹名** | 路径建议：`桌面\新建文件夹\题库_YYYYMMDD.xlsx` |
| **DP 卡住不动 / 处理一半停** | 发"继续处理"催它，或截图它停的地方让它续 |

## 二、一键 Prompt（复制下面整段）

```text
你现在是题库格式化处理专家。我会上传一份医学题库（PDF/DOCX/TXT/Excel 等任意格式），
你必须**完全自主**处理完毕、自检、必要时重做，最后输出一份可直接导入手机搜题
软件的 Excel 文件给我下载。

━━━━━━━━━━ 关键纪律 ━━━━━━━━━━
- 不要询问我任何问题，自己根据资料判断和处理
- 不要等我"继续"，全程一气呵成
- 处理完每一批必须自检；错了立刻自己重做这批，不要让我提醒
- 最后只输出 1 件东西：可下载的 .xlsx 文件 + 一段简短的统计汇报
- 文件命名：题库_YYYYMMDD_v1.xlsx（YYYYMMDD 用今天的日期）

━━━━━━━━━━ 输出 Excel 严格模板 ━━━━━━━━━━

Sheet 名: 题库
列顺序（11 列，列名一字不差）:
  题干 | 题型 | 选项A | 选项B | 选项C | 选项D | 选项E | 选项F | 选项G | 选项H | 正确答案

━━━━━━━━━━ 11 条硬规则（每条都必须遵守） ━━━━━━━━━━

1. 一道题独占一行。绝对不能把多道题塞进同一行，也不能把一道题拆到多行
2. 题干列只填题目正文。删除以下污染:
   - 题号前缀（"1." "3、" "(8)" "第10题"）
   - 章节标签（"一、A1型题" "第一章" "一．单选题（共 1433 题）"）
   - 题干末尾的答案括号（"(C)" "（A）"）
   - 多余空格、换行符、HTML 标签、解析文字
   - 保留原文标点（中文标点别替换成英文）
3. 题型列必须是【单选题/多选题/判断题/填空题】4 个之一，不允许其它值
4. A1/A2/A3/A4/B/B1 型题全部归"单选题"（医学考试这些都是单选格式）
5. 选项列只填内容，不要"A."前缀。例：选项A列写"刺激性咳嗽"不是"A.刺激性咳嗽"
6. 单选答案 = 单字母（A/B/C/D/E/F/G/H）
7. 多选答案 = 连续大写字母无分隔（"ABCDE"，绝不能写"A、B、C"或"A,B,C"）
8. 判断题答案 = A（对）或 B（错）
9. 填空题答案 = 文字。多空用 | 分隔。例："十二指肠|下消化道"
10. 正确答案列绝对不能为空。如果原文找不到答案就跳过这道题，把题号记在
    最后的汇报里，但**不要瞎填**也**不要留空**让它进 Excel
11. A3/A4 案例题：每个子问题独立成一行。题干 = 精简案例(60-100字) + 句号 +
    子问题题干。例：
    "患儿男11岁,右侧腮腺肿大1天,T39.8℃,腮腺管口分泌物。患儿可能的诊断是"

━━━━━━━━━━ 强制工作流（自动执行） ━━━━━━━━━━

【阶段 1: 静默分析原文】
  你自己看原文，**不要告诉我分析过程**。在心里搞清楚:
  - 题号格式
  - 答案标记位置（红字 / 括号 / 单独答案行）
  - 总题量
  - 题型构成
  - 有没有 A3/A4 案例题、B 型题

【阶段 2: 静默分批处理】
  每批 ≤ 30 题（多选 ≤ 20 / A3/A4 案例 ≤ 8 个）。
  你自己分批，不要问我"是否继续"。

【阶段 3: 每批自检（内部进行，不输出过程）】
  每批处理完，你自己在心里运行下面 7 项检查:
    1. 答案列是否有空值？有 → 立刻找原文补，找不到就跳过这题
    2. 题干是否含题号前缀？有 → 删
    3. 题干是否含章节标签？有 → 删
    4. 题干是否含多个问号/多个题？有 → 拆开
    5. 题型字段是否在 4 个标准值里？不在 → 重判
    6. 多选答案是否带分隔符？带 → 删分隔符
    7. 选项是否错位（A 内容到 B 列等）？错 → 校正
  全部通过 → 进入下一批；任意失败 → 重做这一批最多 3 次

【阶段 4: 全局校验（内部进行）】
  全部分批做完后，最后一次全局检查:
    - 总行数 = 阶段 1 估算的题数 ± 5%
    - 各题型分布合理
    - 答案列空率 = 0
    - 抽 10 题对照原文，确认题干 + 选项 + 答案对得上

【阶段 5: 输出最终结果】
  输出 1 个可下载的 .xlsx 文件 + 一段汇报（≤ 200 字）。
  汇报格式:
  ```
  ✅ 处理完成: 题库_20260608_v1.xlsx
  📊 总题数: 5421
     单选题: 4200 / 多选题: 800 / 判断题: 0 / 填空题: 421
  🚫 跳过题: 12 道（原因: 原文无答案，题号: 3,18,156,...）
  🔁 重做批次: 2 批（第 4 批选项错位、第 7 批答案缺失）
  📁 请把 .xlsx 下载并另存到 "桌面\新建文件夹\" 下使用
  ```

━━━━━━━━━━ 失败兜底 ━━━━━━━━━━

如果遇到下面情况，**自己处理，不要问我**:
- 原文某些页扫描不清 → 跳过那部分，最后在汇报里列出
- 答案标记方式不一致 → 按主流标记处理，少数特例跳过
- 案例题切分困难 → 按最合理的方式切，宁可粗也别错
- 输出文件超过 30000 行 → 自动拆成 2-3 个文件（命名加 _part1/_part2/_part3）

━━━━━━━━━━ 开始 ━━━━━━━━━━

我已经在这条消息里上传了题库文件。

现在你立刻开始处理，按 阶段 1 → 5 自动跑完，
最后只给我 1 个 .xlsx 下载链接 + 一段 ≤ 200 字的汇报。

中间不要询问我任何问题，不要等我"继续"。
今天日期是 2026-06-08，文件名用 题库_20260608_v1.xlsx。
```

## 三、DP 处理完后你做的 3 步

### 第 1 步：下载 .xlsx

DP 处理完会给你一个文件下载链接（或附件按钮），点下载。

### 第 2 步：另存到桌面 `新建文件夹`

```
C:\Users\<你的用户名>\Desktop\新建文件夹\题库_20260608_v1.xlsx
```

如果文件夹不存在，先建。

### 第 3 步：跑校验脚本

```bash
cd E:\ziyong\aisouti\docs\scripts
python validate_bank.py "C:\Users\<你的用户名>\Desktop\新建文件夹\题库_20260608_v1.xlsx"
```

**校验输出会告诉你**：
- 🎉 全部通过 → 直接导入 App
- ⚠️ 有警告 → 看一下，少数警告可接受
- ❌ 有致命错误 → **截图错误信息发回 DP**：
  ```
  你输出的题库校验不通过，错误如下：
  [粘贴校验脚本的错误输出]
  
  按这些错误重新处理这些题，重新生成完整 .xlsx。
  ```

## 四、DP 不听话的修复话术（备用）

### DP 问你问题（不该问）：

> "DP，按我之前发的 Prompt 第 3 节'关键纪律'，不要问我，自己判断处理。
> 重新开始，全程不要停。"

### DP 处理到一半停了：

> "继续，按之前的工作流跑到底。直到输出最终 .xlsx 才能停。"

### DP 输出的 .xlsx 没生成只给了 TSV：

> "请把上面 TSV 转成可下载的 .xlsx 文件给我。"

### DP 输出的文件还是有错（校验脚本不通过）：

> "刚才的 .xlsx 校验失败，错误如下：
> [粘贴校验脚本输出]
> 
> 按这些错误**只重做出错的部分**，重新生成完整 .xlsx 给我。"

### DP 处理失败说"原文看不清"：

> "看不清的题列出题号给我，其它能处理的全部输出。我自己补缺失的。"

## 五、复盘：如果你拿到的 .xlsx 还是不对

这种情况下做下面 3 件事**之一**：

### A. 换一个 DP 模型（最快）

DeepSeek、Kimi、Claude、GPT-4 各自表现不同。这家不行换另一家。

### B. 拆小再发

把原文件先用 Word/PDF 工具拆成 3-5 个小文件（每个 ≤ 50 页），
分别发给 DP，最后合并 Excel。

### C. 求助手工

实在不行，把原文件发给客户/题库供应商，让他们提供已经做好的 .xlsx。
我们 1.1.12 App 已经支持任何符合规范的 Excel。
