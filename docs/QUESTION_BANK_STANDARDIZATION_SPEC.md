## 一、给 AI 的开场白（直接粘贴）

```
你是题库格式化处理工具。我会发给你一份或多份不同格式的题库
（PDF / Word / 网页 / 旧 Excel / 教材都可能）。你的任务是把它们解析成
统一的标准 Excel 格式，让我用一个搜题软件可以直接导入并精确匹配。

输出要求：
1. 严格按下面的 Excel 模板输出（11 列，列名一字不差）
2. 一道题占一行
3. 案例题（A3/A4 型）按"每个子问题独立成一行"展开
4. 教材类资料里看到 【ANS:xxx】 这种标记表示这是填空题的答案
5. 不要省略任何题目，逐题处理
6. 处理完后输出可下载的 .xlsx 文件
```

## 二、Excel 标准模板

**列名/顺序/数量都不能错**：

```
| 题干 | 题型 | 选项A | 选项B | 选项C | 选项D | 选项E | 选项F | 选项G | 选项H | 正确答案 |
```

- 第 1 行必须是表头
- 第 2 行开始填数据
- Sheet 名建议 `题库`

## 三、各列填写规则

### 第 1 列：**题干**

| ✅ 该有的 | ❌ 不该有的 |
|---|---|
| 题目正文 | 题号前缀（如"1." "3、" "第3题"）|
| 题目末尾的标点 | 章节标签（如"一、A1型题" "第一章"）|
| 完整问句 | 选项内容（A、B、C 的文字）|
| 案例题：背景 + 子问题题干 | 答案字母 |
| 必要的格式标记（如填空 ____ ）| 多余空格、换行符、HTML 标签 |

**例子**：

| 原始内容 | ✅ 正确写法 | ❌ 错误写法 |
|---|---|---|
| `3、下列哪项是小儿结核病的发病机制(C)` | `下列哪项是小儿结核病的发病机制` | `3、下列哪项是小儿结核病的发病机制(C)` |
| `一、A1型题 8、利福平的主要不良反应` | `利福平的主要不良反应` | `一、A1型题 8、利福平的主要不良反应` |
| `骨由____组成。` | `骨由____组成。` | `骨由（）组成` |

### 第 2 列：**题型**

**必须是下面 4 个值之一**：

| 值 | 适用 |
|---|---|
| `单选题` | A1/A2 型题 / B 型题 / 普通单选 / 配伍题 / 案例题里的单选子问题 |
| `多选题` | 题干含"包括/有哪些/哪几项/有以下"等并列性提问 / 答案 2 个以上字母 |
| `判断题` | 答案"对/错"或"正确/错误" |
| `填空题` | 题干含 `____` 或 `（）` 留空 / 答案是文字（非字母）|

**注意**：
- 不要写"A1型题"、"A2型题"、"B 型题"、"案例题"这些 — **按答题方式归类**，不按教学分类
- 案例题（A3/A4）拆开后，每个子问题按其本身的题型归类

### 第 3-10 列：**选项 A-H**

- **只填选项内容**，不要写 `A.` `A、` `A：` 这种前缀字母
- 每个选项独立一格
- 没有的选项**留空**（如 4 选项的题，E-H 留空）
- 填空题：**全部留空**
- 判断题：可以写 `选项A=对`、`选项B=错`，也可以留空（软件会自动生成）

**例子**：

```
✅ 正确：选项A 列写「刺激性咳嗽」
❌ 错误：选项A 列写「A. 刺激性咳嗽」
❌ 错误：选项A 列写「A、刺激性咳嗽」
```

### 第 11 列：**正确答案**

| 题型 | 正确写法 | 错误写法 |
|---|---|---|
| 单选题 | `A` / `B` / `C` / `D` / `E` | `(A)` / `A.` / `A选项` |
| 多选题 | `ABC` / `ABCD` / `ABCDE`（**字母连写，无分隔符**）| `A,B,C` / `A、B、C` / `A B C` |
| 判断题 | `A`（对）/ `B`（错） 或 `对` / `错` | `正确` / `错误` |
| 填空题 | 直接写答案文本 | `（答案）` 包起来 / 多余引号 |

**多空填空题**：用 `|` 分隔多个答案
```
正确答案列写法：第一空答案|第二空答案|第三空答案
```

## 四、特殊题型处理规则

### A. **案例题（A3/A4 型）** — 共享题干 + 多子问题

**原始格式**：
```
14、患儿男 11岁。发现右侧腮腺肿大 1 天入院。护理体检 T 39.8℃...
1) 患儿可能的诊断是
   A 猩红热  B 流行性腮腺炎  C 麻疹  D 百日咳  E 水痘
   答案: B
2) 该患儿的饮食原则是
   A 低盐低脂  B 低碘  C 淀粉类  D 高蛋白  E 清淡软食
   答案: E
3) 为做好消毒隔离，下列哪项措施是正确的
   A 呼吸道隔离至腮腺肿大完全消退后3天  ...
   答案: A
```

**展开为 3 行**：

| 题干 | 题型 | A | B | C | D | E | 正确答案 |
|---|---|---|---|---|---|---|---|
| 患儿男11岁右侧腮腺肿大1天入院,T39.8℃...。患儿可能的诊断是 | 单选题 | 猩红热 | 流行性腮腺炎 | 麻疹 | 百日咳 | 水痘 | B |
| 患儿男11岁右侧腮腺肿大1天入院,T39.8℃...。该患儿的饮食原则是 | 单选题 | 低盐低脂 | 低碘 | 淀粉类 | 高蛋白 | 清淡软食 | E |
| 患儿男11岁右侧腮腺肿大1天入院,T39.8℃...。为做好消毒隔离，下列哪项措施是正确的 | 单选题 | 呼吸道隔离至腮腺肿大完全消退后3天 | ... | ... | ... | ... | A |

**规则**：
- 案例背景**精简到 60-100 字以内**（保留关键症状/检查值），太长会污染搜索
- 案例背景 + `。` + 子问题题干（用句号或换行连接）
- 选项**只填当前子问题的**，不要把其它子问题的选项混进来

### B. **B 型题（配伍题）** — 几道题共用一组选项

**原始格式**：
```
共用选项：
A. 红细胞  B. 白细胞  C. 血小板  D. 血红蛋白  E. 血浆

1) 携带氧气的细胞 → 答案 A
2) 参与免疫的细胞 → 答案 B
3) 参与凝血的细胞 → 答案 C
```

**展开为 3 行**：

| 题干 | 题型 | A | B | C | D | E | 正确答案 |
|---|---|---|---|---|---|---|---|
| 携带氧气的细胞 | 单选题 | 红细胞 | 白细胞 | 血小板 | 血红蛋白 | 血浆 | A |
| 参与免疫的细胞 | 单选题 | 红细胞 | 白细胞 | 血小板 | 血红蛋白 | 血浆 | B |
| 参与凝血的细胞 | 单选题 | 红细胞 | 白细胞 | 血小板 | 血红蛋白 | 血浆 | C |

**规则**：每行都要**完整复制**那组选项。

### C. **填空题**

```
通常把十二指肠以上的一段称为上消化道，空肠以下的部分称为____。
答案：下消化道
```

→
| 题干 | 题型 | A-H | 正确答案 |
|---|---|---|---|
| 通常把十二指肠以上的一段称为上消化道，空肠以下的部分称为____。 | 填空题 | （全空）| 下消化道 |

### D. **判断题**

```
甲状腺危象是甲亢病情急剧加重。（√）
```

→
| 题干 | 题型 | A | B | 正确答案 |
|---|---|---|---|---|
| 甲状腺危象是甲亢病情急剧加重 | 判断题 | 对 | 错 | A |

## 五、🚨 教材中"红字答案"的特殊处理

### 问题描述

很多教材资料是这样的：
- 教材**正文**含完整内容
- 关键术语/答案**用红色字体标注**
- 把红色字段挖空 → 就是填空题

例如教材原文（**红字** 表示红色字体）：
```
通常把十二指肠以上的一段称为**上消化道**，空肠以下的部分称为**下消化道**。
```

→ 实际是填空题：
```
通常把____以上的一段称为上消化道，空肠以下的部分称为____。
答案：十二指肠 | 下消化道
```

### 为什么 AI 识别不出红字？

- AI（DP / GPT 等）接收的是**纯文本**
- **颜色信息在文本里丢失了**
- AI 看到的就是"上消化道"和"下消化道"，**完全分不清哪个是该挖空的答案**

### 解决方案：预处理把红字转成标记

**在发给 AI 之前**，先用脚本把红色文字转成 `【ANS:xxx】` 标记：

```
原文（含红字）:
  通常把十二指肠以上的一段称为上消化道，空肠以下的部分称为下消化道。
                                ↑(红)              ↑(红)

预处理后:
  通常把十二指肠以上的一段称为【ANS:上消化道】，空肠以下的部分称为【ANS:下消化道】。
```

然后告诉 AI：
> `【ANS:xxx】` 标记包裹的是填空题的答案；
> 你处理时把 `【ANS:xxx】` 替换为 `____`，把 xxx 收集成"正确答案"

最终 Excel 行：
| 题干 | 题型 | 正确答案 |
|---|---|---|
| 通常把____以上的一段称为上消化道，空肠以下的部分称为____。 | 填空题 | 十二指肠\|下消化道 |

> 注意：上面是举例，红色标注的是"上消化道"和"下消化道"还是"十二指肠"和"下消化道"，取决于教材实际怎么标。**脚本会按红色字体如实抓取**。

## 六、数据清洁规则

### 必须删除

- 题号前缀（`1.` / `3、` / `(8)` / `第10题`）
- 章节标签（`一、A1型题` / `第一章` / `内科部分`）
- 答案标记（题干末尾的 `（A）` / `(C)` 等）
- 多余空格（多个空格合并成 1 个，行首尾空格 trim）
- HTML/Markdown 标记（`<br>` / `**` / `[图]` 等）
- 解析/答案分析文字
- 页码 / 章节进度（`第3/200题`）

### 必须保留

- 标点符号（中英文都保留原样，**不要**做"全角转半角"）
- 数字单位（mmol/L / ℃ / mg/dL 等）
- 医学专有符号（`≥` `≤` `→` 等）
- 题干里的占位符（`____` 或 `（  ）`）

### 去重

- 同一题（题干完全一致）只保留一条
- 题干 90% 以上相似的视为重复

## 七、输出文件要求

| 项 | 要求 |
|---|---|
| 文件格式 | `.xlsx`（Office 2007+ 格式，**不要** `.xls`）|
| Sheet 名 | `题库` |
| 表头 | 第 1 行严格按"题干 / 题型 / 选项A...H / 正确答案" |
| 编码 | UTF-8 |
| 单文件题量 | 建议 ≤ 30000 题（再大可分多个文件）|
| 文件命名 | 按学科 + 来源 + 日期，如 `三基题库_护理_20260608.xlsx` |

## 八、AI 自检清单

AI 输出完，让它自检一遍：

- [ ] 总题数 = 原始资料的题数（如果去重，给出去重数）
- [ ] 每行题型字段必须是 4 个标准值之一
- [ ] 多选题答案字段**没有**逗号、顿号、空格
- [ ] 没有题号前缀（题干**不**以数字开头）
- [ ] 没有章节标签污染
- [ ] 案例题已展开为多行（同一案例背景出现 N 次正常）
- [ ] B 型题选项已逐题完整复制
- [ ] 填空题选项列**全空**
- [ ] 红字答案的填空题：题干含 `____`、答案在"正确答案"列
- [ ] 总题数、各题型分布给出统计

## 九、完整 Prompt 模板（粘贴即用）

```text
我现在要把一份医学题库标准化，最终用于手机搜题 App 的精准匹配。
请按下面的规范处理我发给你的所有题库文件，输出一份标准 Excel。

【输出 Excel 模板】
- 文件格式: .xlsx
- Sheet 名: 题库
- 列顺序（11 列）:
  题干 | 题型 | 选项A | 选项B | 选项C | 选项D | 选项E | 选项F | 选项G | 选项H | 正确答案

【字段填写规则】
1. 题干: 只填题目正文。删除题号前缀(如"3、")、章节标签
   (如"一、A1型题")、末尾的答案括号(如"(C)")。保留原文标点。

2. 题型: 必须是【单选题/多选题/判断题/填空题】4 个之一。
   - A1/A2 型题 → 单选题
   - 题干含"包括/有哪些"等并列性提问 → 多选题
   - 对错选择 → 判断题
   - 含 ____ 填空 → 填空题

3. 选项A-H: 只填内容，不要加"A."前缀。填空题全空。

4. 正确答案:
   - 单选: 单字母 (A/B/C/D/E)
   - 多选: 连续大写字母无分隔 (ABCDE)
   - 判断: A=对 / B=错
   - 填空: 答案文本（多空用 | 分隔）

【特殊题型】
- A3/A4 案例题: 每个子问题展开成独立行。题干 = 案例背景(精简到 60-100 字)
  + "。" + 子问题题干。选项只填当前子问题的。

- B 型题(配伍): 每题独立一行，每行完整复制共享的 A-E 选项。

【教材类资料的"红字答案"标记】
- 我会用脚本把教材里的红色字预先转成 【ANS:xxx】 标记
- 你看到 【ANS:某词】 时:
  · 在题干里把它替换成 ____
  · 把"某词"收集到"正确答案"列
  · 题型标"填空题"
- 一句话里多个 【ANS:xxx】 → 题型仍是"填空题"，
  答案列用 | 分隔多个答案

【数据清洁】
必须删除:
  - 题号前缀（如"3、" "(8)" "第10题"）
  - 章节标签（如"一、A1型题" "第一章"）
  - 题干末尾答案括号
  - 多余空格、HTML 标记
  - 解析/分析文字
必须保留:
  - 原文标点（中文标点别替换成英文）
  - 单位、医学符号、占位符 ____

【输出前必做】
- 自动去重（题干完全一致的）
- 抽样自检 10 题
- 统计各题型数量

【现在开始处理】
我把题库文件发你（PDF / DOCX / TXT / 旧 Excel 任意格式），
你按上面规则输出标准 .xlsx 给我。
```

## 十、常见排错

| 现象 | 原因 | 修复 |
|---|---|---|
| 导入失败 / 报"REQUIRED_COLUMN_MISSING" | 列名写错 | 严格按"题干/题型/选项A..." |
| 题型识别为 unknown | 题型列值不在 4 个标准值里 | 重新映射成标准值 |
| 多选题搜出答案是 A 一个字母 | 答案列写成了 "A、B" 不是 "AB" | 去掉所有分隔符 |
| 搜题 miss | 题干含噪音前缀 | 重新清洗题干 |
| 重复出现同一题 | 没去重 | 用题干做 unique |
| 教材填空题题干没下划线，答案串进题干 | 没做红字预处理 | 用第十一节的脚本预处理 |

## 十一、配套预处理脚本

### 脚本 1：**多格式红字 → ANS 标记**（最常用）

把教材里所有红色字体的文字转成 `【ANS:xxx】` 标记，输出 `.txt` 给 AI 处理。

**脚本位置（已在仓库里）**：

```
E:\ziyong\aisouti\docs\scripts\red_to_ans.py     ← 主脚本
E:\ziyong\aisouti\docs\scripts\install_deps.bat  ← 一键装依赖
E:\ziyong\aisouti\docs\scripts\README.md         ← 详细使用说明
```

**支持的格式**（不只是 Word）：

| 后缀 | 格式 | 依赖 |
|---|---|---|
| `.docx` | Word 2007+ | python-docx |
| `.doc` | Word 97-2003 | win32com（仅 Windows）|
| `.pdf` | PDF | PyMuPDF |
| `.xlsx` | Excel | openpyxl |
| `.html / .htm` | HTML 网页 | beautifulsoup4 |
| `.pptx` | PowerPoint 课件 | python-pptx |
| `.rtf` | RTF 富文本 | 内置解析（无外部依赖）|

**使用方法**：

```bash
# 第一次用：装依赖（Windows 双击 install_deps.bat）
pip install python-docx PyMuPDF openpyxl beautifulsoup4 python-pptx pywin32

# 然后按格式处理：
python red_to_ans.py 教材.docx 教材_marked.txt
```

**脚本代码节选**（完整版见 `red_to_ans.py`）：

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
把 .docx 文档中所有红色字体的文字转成 【ANS:xxx】 标记。
用于教材类题库的预处理，让 AI 知道哪些是填空答案。

用法: python red_to_ans.py <input.docx> <output.txt>
"""
import sys
from docx import Document
from docx.shared import RGBColor

def is_red(color):
    """判断 RGBColor 是否为红色系（R 高、G/B 低）"""
    if color is None:
        return False
    if isinstance(color, RGBColor):
        r, g, b = color[0], color[1], color[2]
        # 红色判定：R ≥ 150，G/B ≤ 100，且 R 明显大于 G/B
        return r >= 150 and g <= 100 and b <= 100 and r > g + 50 and r > b + 50
    return False

def extract_with_red_marker(docx_path, out_path):
    doc = Document(docx_path)
    lines = []
    for para in doc.paragraphs:
        buf = []
        for run in para.runs:
            text = run.text
            if not text:
                continue
            try:
                color = run.font.color.rgb if run.font.color and run.font.color.rgb else None
            except Exception:
                color = None
            if is_red(color) and text.strip():
                # 红色字段 → 标记
                buf.append(f'【ANS:{text.strip()}】')
            else:
                buf.append(text)
        line = ''.join(buf).strip()
        if line:
            lines.append(line)
    with open(out_path, 'w', encoding='utf-8') as f:
        f.write('\n'.join(lines))
    print(f'已处理 {len(lines)} 段，输出: {out_path}')

if __name__ == '__main__':
    if len(sys.argv) < 3:
        print('Usage: python red_to_ans.py <input.docx> <output.txt>')
        sys.exit(1)
    extract_with_red_marker(sys.argv[1], sys.argv[2])
```

**输入示例**（教材原文，红字表示红色）：
```
通常把【十二指肠】以上的一段称为上消化道，空肠以下的部分称为【下消化道】。
                ↑红                                                ↑红
```

**输出示例**（`.txt`）：
```
通常把【ANS:十二指肠】以上的一段称为上消化道，空肠以下的部分称为【ANS:下消化道】。
```

把这个 `.txt` 发给 DP，配合第九节的 Prompt，DP 就能自动转成：
| 题干 | 题型 | 正确答案 |
|---|---|---|
| 通常把____以上的一段称为上消化道，空肠以下的部分称为____。 | 填空题 | 十二指肠\|下消化道 |

### 脚本 3：**Excel 验证脚本**（导入前自检）

```python
#!/usr/bin/env python3
"""
验证 AI 输出的 Excel 是否符合规范。
用法: python validate_bank.py <output.xlsx>
"""
import sys
from openpyxl import load_workbook
from collections import Counter

REQUIRED = ['题干', '题型', '选项A', '选项B', '选项C', '选项D',
            '选项E', '选项F', '选项G', '选项H', '正确答案']
TYPES_OK = {'单选题', '多选题', '判断题', '填空题'}

def validate(path):
    wb = load_workbook(path, read_only=True, data_only=True)
    ws = wb.active
    header = [c.value for c in next(ws.iter_rows(min_row=1, max_row=1))]

    print(f'文件: {path}')
    print(f'表头: {header}')
    if header != REQUIRED:
        print(f'❌ 表头不符合规范！应为: {REQUIRED}')
    else:
        print('✓ 表头 OK')

    types = Counter()
    bad_type = 0
    bad_ans = 0
    empty_stem = 0
    qno_prefix = 0
    total = 0
    for row in ws.iter_rows(min_row=2, values_only=True):
        total += 1
        stem, qtype, *opts, ans = row[:11]
        if not stem or not str(stem).strip():
            empty_stem += 1
            continue
        s = str(stem).strip()
        # 题号前缀检查
        if s[:1].isdigit() and any(s.startswith(f'{i}') for i in range(0, 10000)):
            import re
            if re.match(r'^\d+[、.,)）]', s):
                qno_prefix += 1
        if qtype not in TYPES_OK:
            bad_type += 1
        else:
            types[qtype] += 1
        if qtype == '多选题' and ans:
            ans_s = str(ans).strip()
            if ',' in ans_s or '、' in ans_s or ' ' in ans_s:
                bad_ans += 1

    print(f'\n=== 统计 ===')
    print(f'总行数: {total}')
    print(f'题型分布: {dict(types)}')
    print(f'❌ 题型不规范: {bad_type}')
    print(f'❌ 多选答案含分隔符: {bad_ans}')
    print(f'❌ 题干为空: {empty_stem}')
    print(f'❌ 题干含题号前缀: {qno_prefix}')

if __name__ == '__main__':
    validate(sys.argv[1])
```

## 十三、需要注意的细节

1. **DP 处理大文件时可能要分批**：超过 5000 题的资料 DP 会让你分段。每段保持表头一致即可。
2. **抽样验证**：DP 处理完后，你**随机抽 20 道**对比原文是否准确。
3. **导入测试**：先导一小份（100 题）到 App 测一下，确认能正常匹配，再导全量。
4. **来源记录**：在表外（如 Sheet 2）记录"原始文件名 → 处理日期 → 处理者备注"，将来追溯方便。
5. **教材类资料一定要预处理红字**：跳过这一步 → AI 看不懂哪是答案 → 输出乱七八糟。
